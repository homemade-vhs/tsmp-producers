Themes & defaults
A theme is every setting except the patron name lists, as a .json file: send it to the editors and they import it to get the exact same look. Importing applies it straight away; "Save current as my defaults" makes this browser's Reset button come back to it.
Timing
Load-in: the grid first shows only its solid background, then the boxes pop in top to bottom, then the text and images. Hold keeps the scroll frozen (the clock still ticks); the total duration doesn't change, so the scroll runs a little faster to make up for it.
The scroll accelerates from standstill to full speed over the ease-in, and glides between the two section speeds over the speed change (centred on the moment the Producers header locks). Speeds are re-solved so the total still lands exactly on the last frame. Whole pixels keeps everything crisp but steps unevenly when the speed isn't a whole number of pixels per frame; sub-pixel blends rows between pixels for an even glide (locked headers and the clock stay crisp).

Headers
The opening header is the very first header, above the Executive Producers header (a date, the episode number…). With the locked lead-in it's what's showing at t = 0, then the Exec header pushes it out. Pair it with "Hold at start" so it stays up for a moment. Blocks placed at "Start" sit under it.

Banners & blocks
A block is an optional header followed by any number of banners: a single banner, a banner with a header on top, or one header with several banners under it. A block's header locks at the top like a section header until the next header pushes it out. Banners, blocks and header styles are saved in this browser (…); export the library to back them up.

        Exact px sets the font size in render pixels and overrides Size %. Use it for pixel fonts: PrevueGrid is drawn on a 25-pixel grid, so 25 px makes every font pixel exactly one screen pixel (the faint number is the automatic size). Size % scales that text from its normal size. Width % squeezes it horizontally (92 = the greybox's condensed look; use 100 for fonts that are already narrow). Untick Bold for pixel fonts — the browser fakes bold by smearing them.
        Text style — alignment, padding, shadow, stroke
        For the full crisp low-res look: set Output → Internal render to e.g. 640x480 and Upscale to nearest, then pick pixel text here. Everything is drawn at that small size and blown up with hard pixels on export.
        Padding is the gap between the text and the inside of the box's bevel (px at 1080p). "2 lines" lets long text wrap onto a second line instead of shrinking. The box never changes size, so if two lines don't fit the row height the text gets a bit smaller to fit (raise Row height in Look for room). Shadows and strokes are solid (no blur).
        Header clock
        Custom text replaces the clock in its box everywhere (every header, or the pinned clock). It's shrunk to fit the box like any other text; Min font scale applies.
        Promo panel
        Transitions play at the start of each panel (not the first). Adding an image with the same name as one already here replaces it, so re-exported designs update in place. Saved in this browser; included in exported themes when "include banners…" is ticked.
        Output
        Row heights, fonts and tile widths scale with the frame height (1.0 = the 1080p look). Lower the design scale to fit more rows or longer names in a 4:3 frame. Internal render draws everything at that small size, then scales it up to the output resolution. With nearest neighbour, a whole-number ratio gives perfectly even pixels: 832×624 and 416×312 divide 3328×2496 exactly, while 640×480 is 5.2× so some pixels come out 5 wide and some 6.
